# 友爱日记 · 手机端 H5 演示站

品牌名「友爱日记」（谐音：友≈有、爱≈癌；对外呈现为有爱心的日记社区）。

疗愈向日记 + **社区 demo**：个人记录可「仅自己 / 分享到社区」；社区含动态 Feed、话题筛选、小圈子、同路人、点赞评论（全本地）。

> **这是产品体验演示，不是生产系统，也不是医疗建议。演示数据无服务端。**

## 已实现

### 个人日记
- 登录 / 退出
- 首页：问候、「今日一记」、社区精选入口、本地日记列表
- 写一记：选图／拍照、打字、按住说话；可见性「仅自己｜分享到社区」+ 话题
- 「生成日记」：前端模板整理（演示，不调用付费 AI）
- 日记详情：编辑（含改可见性）、删除、长图、分享预览

### 社区 demo（假数据装满）
- 底栏五栏：`首页 | 社区 | 记录 | 日记本 | 我的`
- **动态**：话题 chips 筛选、同路人公开日记 Feed、进详情、点赞、写评论
- **小圈子**：4 个圈子列表、进圈看动态、加入／已加入（本地）
- **同路人**：推荐用户、简易主页与 TA 的公开日记
- 个人日记选「分享到社区」后出现在 Feed（作者显示为「我」）

### 数据结构（见 `data.js`）
```
users[], topics[], circles[],
posts[{id,userId,circleId?,topicIds[],title,body,images[],likeCount,likedByMe,createdAt,visibility,diaryId?}],
comments[{id,postId,userId,body,createdAt}]
```
Seed 规模约：7 用户、5 话题、4 圈子、12 帖、22 条评论。
