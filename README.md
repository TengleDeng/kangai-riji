# 抗癌日记 · 手机端 H5 演示站

疗愈向日记产品原型：拍照 / 打字记录心情 → 本地模板整理成一篇日记 → 编辑、生成长图、分享预览。

> **这是产品体验演示，不是生产系统，也不是医疗建议。**

## 已实现

- 登录 / 退出
- 首页：问候、「今日一记」、本地日记列表
- 写一记：选图／拍照、打字、按住说话（MediaRecorder；无权限或失败则提示改用打字）
- 「生成日记」：前端模板断句／标题／标签（标注为演示，不调用付费 AI）
- 日记详情：图 + 正文 + 标签；编辑、删除、html2canvas 生成长图
- 分享预览：卡片、复制本站链接、生成／保存长图；注明默认仅本机可见
- 日记本列表、「我的」页（退出、清空本机数据）

## 未实现 / 刻意不做

- 真实服务端账号、云同步、亲友只读链接鉴权
- 语音转文字、大模型 API
- 微信小程序能力（登录、订阅消息、小程序码）
- 医疗报告解读、绿通、问诊
- 检测报告上传与合规存储

## 本地打开

直接用浏览器打开 `index.html`，或：

```bash
cd web   # 或仓库根目录
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 技术

纯前端：`index.html` + `styles.css` + `app.js`，html2canvas（CDN）。奶油纸 + 鼠尾草绿视觉。
