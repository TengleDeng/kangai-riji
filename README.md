# 友爱日记 · 手机端 H5 演示站

品牌名「友爱日记」（谐音：友≈有、爱≈癌；对外呈现为有爱心的日记社区）。

疗愈向日记 + **社区 demo**。v2 重点服务两端：**记录者**（写完有成就感、日记本好翻、可见性一键改）与 **分享者**（分享后马上被看见、被接住；长图一键发给家人）。

> **这是产品体验演示，不是生产系统，也不是医疗建议。演示数据无服务端。**

## 已实现

### 记录者价值（写日记的人）
- 首页「连续记录 N 天」卡：本周篇数 / 总篇数 / 已分享数，点进心情回顾
- 写一记：顶部「今天记一句就好」降低空白压力；**心情选择**（7 种）；**提示语 chips**（「今天想谢谢…」等）一点即填；配图、按住说话、打字
- 生成后弹出 **「已保存」成就卡**：连续天数、本周篇数、心情；可直达「做成长图发给家人」
- **日记本**：统计条（篇数 / 连续 / 本周 / 已进社区）、近 7 天心情回顾、筛选「全部｜仅自己｜已进社区」、**按日分组**浏览、每篇可见性标签 + **一键改可见性**（分享时弹出话题选择，必选）
- 日记详情：可见性 + 心情徽章；已分享的显示「社区回应」（赞 / 抱抱 / 留言摘要），未分享的给出「想被看见吗？」入口
- 原有：编辑（含改可见性）、删除（同步撤下社区帖）、长图、语音录制

### 分享者价值（发到社区 / 转给亲友的人）
- 分享后约 5 秒模拟一位同路人「抱抱 + 暖心留言」（演示），toast 提示，计数实时变化
- 首页「💌 你的分享被接住了」卡：赞 / 抱抱 / 留言总数 + 最新回应（含「新」标记）
- 「我的」：6 格统计（日记、连续、分享、收到的赞 / 抱抱 / 留言）、心情回顾、**收到的回应列表**、已加入圈子、已关注的人；底栏「我的」有未读红点
- Feed 顶部「我的分享」筛选 chip；自己的帖有「我的分享」角标与淡粉底，详情页有「做成长图发给家人」
- 分享卡文案改为亲友向：「想让你看见我的这一天 · 不用给建议，读完回我一句『我在』，我就被接住了」；按钮「生成长图｜复制文字｜也分享到社区 / 看社区回应」

### 社区（假数据装满）
- 底栏五栏：`首页 | 社区 | 记录 | 日记本 | 我的`；社区内二级导航 `动态 | 小圈子 | 同路人`
- **动态**：发帖入口卡；横滑 chips「全部 / 我的分享 / 关注 / 9 个话题」+ 筛选摘要；首次进入骨架屏加载态；卡片含头像、昵称、城市、相对时间、所属圈子、正文 3 行折叠「展开全文」、配图、心情·天气·地点小标签、话题 chip（可点筛选）、最新评论预览、♥ 赞 / 🤗 抱抱 / 💬 评论（点按弹跳 + 飘心）
- **帖子详情**：全文、关注作者、来源圈子跳转、评论列表（「作者」标记、点头像进主页）、**快捷暖语** chips、发评论（本机保存、新评论高亮）
- **小圈子**：分「我加入的 / 推荐给你」；卡片含封面 emoji、简介、圈规、成员头像叠放、人数 / 圈内帖数 / 今日新增、加入按钮；圈页含统计、圈规、成员预览（可点进主页）、圈内 Feed、已加入后「在圈子里分享」
- **同路人**：按共同话题 + 同城排序；卡片显示同城标、共同话题、新人标、公开日记数 / 粉丝、关注按钮；主页含 bio、加入天数、4 格统计（公开日记 / 粉丝 / 获赞 / 抱抱）、共同话题高亮、所在圈子、TA 的公开日记
- 首页「社区今日精选」横滑卡片（4 条，可点进详情）
- 空态均有友好文案与下一步按钮

### 数据结构（见 `data.js` 顶部 Schema 注释）
```
users[{id,nickname,city,bio,avatar,topicIds[],followers,following,joinedDays}]
topics[{id,name,emoji,desc}]
circles[{id,name,intro,rule,memberCount,todayPostCount,coverEmoji,coverColor,memberIds[]}]
posts[{id,userId,circleId?,topicIds[],title,body,images[],mood?,weather?,location?,likeCount,hugCount,createdAt,visibility,featured?,diaryId?}]
comments[{id,postId,userId,body,createdAt}]
diaries[{id,title,body,tags[],images[],mood,createdAt,visibility,topicIds[]}]
可选关系：likes / hugs / memberships / follows（demo 存 localStorage 数组）
```
Seed 规模：**12 用户（含「我」）· 9 话题 · 6 圈子 · 31 帖（21 张配图，跨 14 天，含 2 条「我」的分享）· 90 条评论 · 8 篇「我」的个人日记 · 7 种心情**。

localStorage：`youai_community_v2`（自动清除旧 `v1`）、`kangai_diaries`、`youai_diary_seed_v2`（v2 日记 seed 只写一次，保留用户自写日记）。「我的 → 清空」会重置为演示数据。
